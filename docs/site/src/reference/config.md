# Configuration reference

Every key `Config::default()` produces, grouped by TOML section and generated from the compiled defaults plus hand-written prose. A key here always exists in the current release; if it's missing, the build would have failed first.

## General {#config-section-root}

Options that live at the top level of the file, outside any `[section]`.

### allow_osc52_read {#config-allow_osc52_read}

Lets the running program read the clipboard via OSC 52. Off by default so an untrusted or remote program cannot read the clipboard silently.

Type: `boolean`. Default: `false`.

### bold_is_bright {#config-bold_is_bright}

Maps SGR bold text to the bright variant of its ANSI color. Equivalent to `[theme].bold_is_bright`, and OR'd with it: either one being true enables the mapping.

Type: `boolean`. Default: `false`.

### keys {#config-keys}

User-defined keybinding overrides, mapping a chord string to an action name; see the keybindings reference for the accepted values on both sides. Empty by default.

Type: `table`. Default: `{}`.

### remote_control {#config-remote_control}

Opens a local control socket so other processes on this machine can read the screen and inject keys. Off by default.

Type: `boolean`. Default: `false`.

## Font {#config-section-font}

Typeface, size, and glyph placement used by the GPU text renderer.

### font.builtin_box_drawing {#config-font-builtin_box_drawing}

Draws box-drawing (U+2500-U+259F) and Powerline separator (U+E0B0-U+E0B3) glyphs procedurally instead of relying on the font to include them.

Type: `boolean`. Default: `true`.

### font.fallback {#config-font-fallback}

Fallback font families tried in order when the primary family is missing a glyph, such as emoji, CJK, or symbol fonts.

Type: `array of strings`. Default: `[]`.

### font.family {#config-font-family}

Font family name, resolved through fontdb. Defaults to a Nerd Font on Linux and Cascadia Mono on Windows, so box-drawing and Powerline glyphs render without extra setup.

Type: `string`. Default: `"FiraCode Nerd Font Mono"`.

### font.glyph_offset.x {#config-font-glyph_offset-x}

Fine horizontal pixel offset applied to every glyph within its cell, for fonts whose glyphs need nudging.

Type: `float`. Default: `0.0`.

### font.glyph_offset.y {#config-font-glyph_offset-y}

Fine vertical pixel offset applied to every glyph within its cell, for fonts whose baseline needs nudging.

Type: `float`. Default: `0.0`.

### font.ligatures {#config-font-ligatures}

Enables multi-character ligature shaping. Off by default, since ligatures can visually merge adjacent operators in code.

Type: `boolean`. Default: `false`.

### font.line_height {#config-font-line_height}

Line height multiplier applied to the cell grid.

Type: `float`. Default: `1.0`.

### font.size {#config-font-size}

Font size in points.

Type: `integer`. Default: `12`.

### font.text_contrast {#config-font-text_contrast}

Strength of the contrast curve baked into the glyph mask at rasterization time (0.0 to 1.0, default 0.6). On dark themes it thickens strokes and on light themes it thins them, following the theme's polarity. `0.0` disables the curve. The mask is shared across all cell colors, so the curve cannot adapt to each cell's specific fg/bg pair.

Type: `float`. Default: `0.6`.

## Window {#config-section-window}

Startup size, decorations, opacity, and padding of the terminal window.

### window.app_id {#config-window-app_id}

Wayland app_id and X11 WM_CLASS instance/class. Applied when the window is created. Default "baud". The --app-id CLI flag overrides this value. Changing it requires a restart.

Type: `string`. Default: `"baud"`.

### window.decorations {#config-window-decorations}

Window decorations: "system" uses the native title bar, "custom" draws Baud's unified title bar with inline tabs and window controls, and "none" removes decorations entirely. The previous boolean values still work: true maps to "system" and false to "none".

Type: `string`. Default: `"system"`.

### window.height {#config-window-height}

Initial window height in logical pixels. Only applies when `startup` is "windowed".

Type: `integer`. Default: `600`.

### window.opacity {#config-window-opacity}

Window opacity from 0 to 1. Values below 1 let the desktop show through the background wherever the GPU backend supports transparency.

Type: `float`. Default: `1.0`.

### window.padding_x {#config-window-padding_x}

Extra horizontal pixels of blank space between the window edge and the terminal grid.

Type: `integer`. Default: `0`.

### window.padding_y {#config-window-padding_y}

Extra vertical pixels of blank space between the window edge and the terminal grid.

Type: `integer`. Default: `0`.

### window.startup {#config-window-startup}

Initial window state: "windowed", "maximized", or "fullscreen".

Type: `string`. Default: `"windowed"`.

### window.width {#config-window-width}

Initial window width in logical pixels. Only applies when `startup` is "windowed".

Type: `integer`. Default: `800`.

## Selection {#config-section-selection}

Mouse selection behavior: what counts as a word, when selecting also copies, and which modifiers bypass the running program's own mouse reporting.

### selection.bypass_mouse_reporting_modifiers {#config-selection-bypass_mouse_reporting_modifiers}

Modifier keys that suppress the running program's own mouse reporting so Baud's selection takes over instead, even in mouse-aware apps like vim or tmux.

Type: `array of strings`. Default: `["shift"]`.

### selection.copy_on_select {#config-selection-copy_on_select}

Copies the selection to the clipboard automatically when the left mouse button is released.

Type: `boolean`. Default: `false`.

### selection.copy_on_select_delay_ms {#config-selection-copy_on_select_delay_ms}

Delay after releasing the mouse button before copy-on-select fires, so a click that is about to extend into a drag is not copied prematurely.

Type: `integer`. Default: `500`.

### selection.copy_on_select_target {#config-selection-copy_on_select_target}

Clipboard destination for copy-on-select: "primary", "clipboard", or "both".

Type: `string`. Default: `"both"`.

### selection.smart_selection {#config-selection-smart_selection}

Expands a double-click to a whole URL, path, or email address instead of stopping at the nearest delimiter.

Type: `boolean`. Default: `true`.

### selection.word_delimiters {#config-selection-word_delimiters}

Characters treated as word boundaries for a non-smart double-click selection.

Type: `string`. Default: `` ",│`|:\"' ()[]{}<>\t" ``.

## Paste {#config-section-paste}

Confirmation before pasting text that would execute or hide control characters when the running program has not enabled bracketed paste.

### paste.confirm {#config-paste-confirm}

When to ask before pasting without bracketed paste: "risky" (default) confirms multiline or control-character pastes; "never" pastes immediately.

Type: `string`. Default: `"risky"`.

## Scrollback {#config-section-scrollback}

How much terminal history is kept, and how fast the mouse wheel moves through it.

### scrollback.faux_multiplier {#config-scrollback-faux_multiplier}

Synthetic arrow-key presses sent per mouse wheel tick while an alternate-screen application, such as a pager or editor, owns the scrolling.

Type: `float`. Default: `3.0`.

### scrollback.lines {#config-scrollback-lines}

Maximum number of scrollback lines retained. `0` keeps no history at all.

Type: `integer`. Default: `10000`.

### scrollback.multiplier {#config-scrollback-multiplier}

Lines scrolled per mouse wheel tick while browsing normal-screen scrollback.

Type: `float`. Default: `3.0`.

### scrollback.unlimited {#config-scrollback-unlimited}

Ignores `scrollback.lines` and keeps every line for the life of the session.

Type: `boolean`. Default: `false`.

### process.distro {#config-process-distro}

Type: `table`. Default: `{}`.

### process.kind {#config-process-kind}

Session backend: "native" for the platform's own shell, or "wsl" to run inside a WSL distribution (Windows only).

### process.login {#config-process-login}

Launches the shell as a login shell.

Type: `boolean`. Default: `false`.

### process.program {#config-process-program}

Shell executable to launch. Defaults to `$SHELL` on Unix or `%COMSPEC%` on Windows.

Type: `string (optional)`. Default: *(not set)*.

### process.startup_command {#config-process-startup_command}

Command typed into the shell automatically right after it starts.

Type: `string (optional)`. Default: *(not set)*.

### process.working_directory {#config-process-working_directory}

Initial working directory for the child process; unset uses Baud's own working directory.

Type: `string (optional)`. Default: *(not set)*.

### process.wsl_cwd {#config-process-wsl_cwd}

Initial working directory inside the WSL distribution, passed via `--cd`.

Type: `string (optional)`. Default: *(not set)*.

## Panes {#config-section-panes}

Split-pane layout, using the same dwindle algorithm as Hyprland.

### panes.max {#config-panes-max}

Maximum number of panes per tab. `0` means no limit.

Type: `integer`. Default: `12`.

### panes.preserve_split {#config-panes-preserve_split}

Keeps each pane's split orientation fixed across resizes instead of recalculating it. `smart_split` implies this as well.

Type: `boolean`. Default: `false`.

### panes.smart_split {#config-panes-smart_split}

Chooses a new split's orientation from where the mouse is within the pane, like Hyprland's dwindle triangles, instead of always splitting the long axis.

Type: `boolean`. Default: `false`.

### panes.split_width_multiplier {#config-panes-split_width_multiplier}

Hyprland-style `split_width_multiplier`: biases new splits wider or narrower than an even half.

Type: `float`. Default: `1.0`.

## Diagnostics {#config-section-diagnostics}

Local troubleshooting: the event-loop watchdog, log level, and opt-in crash reporting.

### diagnostics.latency_probe {#config-diagnostics-latency_probe}

Measures key-to-presentation latency (from `KeyboardInput` to `frame.present()`), logging p50/p90/p99/max every 60 samples and again on exit. This is a strict lower bound: it excludes keyboard, compositor, and panel latency.

Type: `boolean`. Default: `false`.

### diagnostics.log_level {#config-diagnostics-log_level}

Default log level for the `baud` tracing target; ignored when `RUST_LOG` is set in the environment.

Type: `string (optional)`. Default: *(not set)*.

### diagnostics.reporting.dsn {#config-diagnostics-reporting-dsn}

Sentry DSN to report to; unset uses the DSN baked in at build time (`BAUD_SENTRY_DSN`).

Type: `string (optional)`. Default: *(not set)*.

### diagnostics.reporting.enabled {#config-diagnostics-reporting-enabled}

Whether remote crash reporting (Sentry) is turned on; unset means the user has not been asked yet.

Type: `boolean (optional)`. Default: *(not set)*.

### diagnostics.watchdog {#config-diagnostics-watchdog}

Runs a background thread that detects an unresponsive event loop. Requires a restart to take effect.

Type: `boolean`. Default: `false`.

## Render {#config-section-render}

GPU redraw pacing.

### render.max_fps {#config-render-max_fps}

Maximum redraw rate in frames per second. Unset uses the monitor's native refresh rate; `0` removes the cap entirely.

Type: `integer (optional)`. Default: *(not set)*.

### render.vsync {#config-render-vsync}

Synchronize presentation with the monitor refresh rate. Disabling it lowers input latency at the cost of possible tearing.

Type: `boolean`. Default: `true`.
